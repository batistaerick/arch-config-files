# Eitr category artwork

`dark.png` and `light.png` are the branded Dark/Light carousel cards. PNG takes
precedence; the older JPG cards remain as fallback assets. Theme-specific previews
are unchanged.

Generated with the built-in image-generation tool, using
`branding/source/05b-rune-liquid.png` as the logo geometry reference.

Shared prompt: Create one restrained landscape 16:9 category image for Eitr's
theme-selection carousel. Preserve the organic liquid-pool silhouette and angular
negative-space rune E; remove the reference caption. One centered logo occupying
about 40% of canvas height, balanced empty space, minimalist flat graphic. No text,
bubbles, drips, patterns, props, 3D, glow, or fancy effects.

Dark palette: very dark forest-green background `#10231c`, muted jade-green logo
`#68aa87`, rune cutout matching the background.

Light palette: nearly white faintly green background `#f3f8f1`, deep forest-green
logo `#32644c`, rune cutout matching the background.
